# Core features

- Users and roles (member, keeper, admin, owner)
- Photo gallery with accent-insensitive search and filters
- One QR code per piece and per box, printable labels
- Boxes in the container, with location and optional dimensions/position
- Check in / check out / move, condition tracking, full history per piece
- Scanner (in/out and look-up modes), installable web app
- Selection: "where are they?" grouped by box and borrower, bulk actions
- Loans with due dates, overdue badges, reminder text messages
- Natural-language search (local embedding model), identical pieces grouped in the gallery
- 3D map of the container: place and drag boxes, highlight where selected pieces are
