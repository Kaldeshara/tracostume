# Core features

- Users and roles (dancer, repairer, choreographer, keeper, admin, owner); loans with a contact
  choreographer and a "collected" step before the piece is back in the container
- Photo gallery with accent-insensitive search and filters
- One QR code per piece and per box, printable labels
- Boxes in the container, with location and optional dimensions/position
- Check in / check out / move, condition tracking, full history per piece
- Scanner (in/out and look-up modes), installable web app
- Selection: "where are they?" grouped by box and borrower, bulk actions
- Loans with due dates, overdue badges, reminder text messages
- Natural-language search (local embedding model), identical pieces grouped in the gallery
- 3D map of the container: storage units of several kinds (boxes, bags, clothes rails), drag and
  stack them, editable container size and door side, highlight where selected pieces are
- Costume sets and show lists, loaded into the selection for bulk actions
- Offline scanner: cached page, pieces copied on the phone, queued actions sent later
- Daily push reminders for overdue and due-tomorrow loans
- Admin password reset links, sign-in attempt limit
